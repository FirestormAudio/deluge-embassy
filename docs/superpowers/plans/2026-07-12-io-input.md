# Audio Input (IO-1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the Deluge's already-captured stereo codec input as a width-2 graph source (`In.line()`), routable through the existing effect/synth graph.

**Architecture:** A new stateless `Kind::Input` node (width-2, port0=L/port1=R). The engine gains `in_l`/`in_r` block rows, filled from a new `render(out, input)` parameter; `render_block` copies those rows into the `Input` node's output ports via a small kind-dispatch branch (no `process_resolved` change). A trivial Wren `In.line()` factory (`NewNode{Input}`, no BindTable/SetParam/args) composes with existing `Mul`/`Pan`/bus/`Out.patch`. Firmware stops discarding the pre-loaded codec input.

**Tech Stack:** Rust `no_std` (crates `deluge-audio-graph`, `deluge-wren-core`, `wren-firmware`); Wren scripting via `wren-sys`. No new DSP kernel (the node is a block copy).

## Global Constraints

- `no_std`, no heap, **no panic on any input** — the `render` input-length guard (`input.get(i)`) covers short/empty/over-long slices.
- 32-bit-`usize` safe: the copy indexes `0..BLOCK` only.
- Stereo convention: port0 = L, port1 = R (matches `Kind::Pan`/`StereoVoiceSum`).
- Purely additive except the `Engine::render` signature (+`input: &[StereoFrame]`); no existing node/render behavior changes; `process_resolved` UNCHANGED; no new `Cmd`.
- Wren: any new foreign-arg read uses the `checked_*` slotapi guards (IO-1 adds none — `In.line()` takes no args).
- Tests run per-crate (NEVER `--workspace`), BOTH configs (default + `--features deluge-dsp-kernels/simd` for graph/wren-core), target `x86_64-unknown-linux-gnu`. `armv7a … can't find crate for test` LSP output is noise.
- MIT/Apache-2.0.

```rust
    pub fn render(&mut self, out: &mut [StereoFrame], input: &[StereoFrame]) {
        // Fill the stereo line-in rows from `input`; frames beyond `input.len()`
        // (including an empty slice) read as silence — no panic on any length.
        for i in 0..BLOCK {
            match input.get(i) {
                Some(f) => { self.in_l[i] = f.l; self.in_r[i] = f.r; }
                None => { self.in_l[i] = 0.0; self.in_r[i] = 0.0; }
            }
        }
        // Zero buses.
        for b in 0..BUSES {
            self.bus_l[b] = [0.0; BLOCK];
            self.bus_r[b] = [0.0; BLOCK];
        }
        self.render_block();
        // ... unchanged: apply bus writes, copy root to out ...
```
