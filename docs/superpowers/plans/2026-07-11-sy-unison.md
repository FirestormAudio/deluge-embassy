# Sy-5e: Unison Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stack up to `VOICES` detuned voices per note (mono and poly) via `synth.unison = N` + `synth.detune = cents`, with 1/√N amplitude normalization.

**Architecture:** Both allocators drive U detuned lanes per note (poly: `pick_lane`×U + release-all-`Held(note)`, reusing 5d release-tail; mono: lanes 0..U). A shared `unison_offset` helper spreads detune; `VoiceSum` gains a gain (default 1.0) set to 1/√N. Two live Synth setters.

**Tech Stack:** Rust `no_std`, `deluge-dsp-kernels` / `deluge-audio-graph` / `deluge-wren-core` (Wren scripting).

## Global Constraints

- **Device-first:** `no_std`, no heap, no panics in DSP/control paths. `VOICES == 8`.
- **Licensing:** MIT / Apache-2.0 only. No GPL.
- **Non-breaking:** `unison == 1` builds/renders byte-identically (poly AND mono); `VoiceSum` default gain 1.0.
- **Two registration tables:** new Wren foreign setters go in BOTH `register_audio` (`bindings_audio.rs`) AND the `wren-sys-backend` `METHODS` table (`bindings.rs`) — the latter is what the test VM boots.
- **Test invocation (per-crate, never `--workspace`; both configs; use `-- name1 name2`):**
  - Kernels: `cargo test --target x86_64-unknown-linux-gnu -p deluge-dsp-kernels <name>` (+ `--features simd`).

```rust
/// Collapse the `VOICES`-lane tile to mono, scaled by `gain` (1.0 = plain sum;
/// unison sets 1/√U to keep level ~constant across U stacked voices).
pub fn voice_sum(tile: &[f32], out: &mut [f32], gain: f32) {
    for i in 0..out.len() {
        let mut s = 0.0;
        for v in 0..VOICES {
            s += tile[i * VOICES + v];
        }
        out[i] = gain * s;
    }
}
```

- [ ] **Step 3: Add `unison_offset` + the fields/setters**

Free fn (near the top of voice.rs):

```rust
/// Semitone offset for unison voice `u` of `count`, spread symmetrically and
/// evenly over ±`detune_cents`. `count <= 1` ⇒ 0.0 (no detune).
fn unison_offset(u: usize, count: usize, detune_cents: f32) -> f32 {
    if count <= 1 { return 0.0; }
    let t = -1.0 + 2.0 * (u as f32) / ((count - 1) as f32); // -1..+1
    t * detune_cents / 100.0
}
```

- [ ] **Step 4: Rework `note_on`/`note_off` for U lanes**

`note_on` — allocate U lanes (mark-and-pick), detuned:

```rust
pub fn note_on(&mut self, note: u8, vel: u8, emit: &mut impl FnMut(Cmd)) {
    if vel == 0 { self.note_off(note, emit); return; }
    let u_count = self.unison.min(VOICES);
    for u in 0..u_count {
        let lane = self.pick_lane();
        self.lane_state[lane] = LaneState::Held(note);
        self.lane_age[lane] = self.clock;
        self.clock = self.clock.wrapping_add(1);
        let value = note as f32 - A440_NOTE + unison_offset(u, u_count, self.detune_cents);
        emit(Cmd::SetParam { node: self.pitch_node, param: lane as u8, value });
        if let Some(vn) = self.vel_node {
            emit(Cmd::SetParam { node: vn, param: lane as u8, value: vel as f32 / 127.0 });
        }
        self.gate_all(lane, true, emit);
    }
}
```

`note_off` — release EVERY lane holding `note`:

```rust
pub fn note_off(&mut self, note: u8, emit: &mut impl FnMut(Cmd)) {
    for v in 0..VOICES {
        if self.lane_state[v] == LaneState::Held(note) {
            self.gate_all(v, false, emit);
            self.lane_state[v] = LaneState::Releasing;
            self.lane_age[v] = self.clock;
            self.clock = self.clock.wrapping_add(1);
        }
    }
    // Unheld note → no-op.
}
```

`all_notes_off` is unchanged (already releases every held lane).

> `pick_lane` marks nothing itself — the loop sets `lane_state[lane] = Held(note)` BEFORE the next `pick_lane`, so each iteration's lane is excluded from the next pick (a `Held` lane is only picked as a last resort via the oldest-Held fallback, and only once all Free/Releasing are taken). For U ≤ number of Free/Releasing lanes, the U lanes are distinct; if U exceeds available lanes, later picks steal the oldest-Held — still distinct because each is marked `Held(note)` immediately.

```rust
pub fn note_on(&mut self, note: u8, vel: u8, emit: &mut impl FnMut(Cmd)) {
    if vel == 0 { self.note_off(note, emit); return; }
    let from_silence = self.len == 0;
    if self.len == MONO_STACK { for i in 1..MONO_STACK { self.notes[i - 1] = self.notes[i]; } self.len -= 1; }
    self.notes[self.len] = note;
    self.len += 1;
    let u_count = self.unison.min(VOICES);
    for u in 0..u_count {
        let value = note as f32 - A440_NOTE + unison_offset(u, u_count, self.detune_cents);
        emit(Cmd::SetParam { node: self.pitch_node, param: u as u8, value });
        if let Some(vn) = self.vel_node {
            emit(Cmd::SetParam { node: vn, param: u as u8, value: vel as f32 / 127.0 });
        }
        if from_silence {
            emit(Cmd::TriggerVoice { node: self.slew_node, voice: u as u8 });
            self.gate_all(u, true, emit);
        }
    }
}
```

`note_off` — loop the glide-back / release over U lanes:

```rust
pub fn note_off(&mut self, note: u8, emit: &mut impl FnMut(Cmd)) {
    let mut idx = None;
    for i in 0..self.len { if self.notes[i] == note { idx = Some(i); break; } }
    let Some(i) = idx else { return; };
    let was_top = i == self.len - 1;
    for j in (i + 1)..self.len { self.notes[j - 1] = self.notes[j]; }
    self.len -= 1;
    let u_count = self.unison.min(VOICES);
    if self.len == 0 {
        for u in 0..u_count { self.gate_all(u, false, emit); }
    } else if was_top {
        let top = self.notes[self.len - 1];
        for u in 0..u_count {
            let value = top as f32 - A440_NOTE + unison_offset(u, u_count, self.detune_cents);
            emit(Cmd::SetParam { node: self.pitch_node, param: u as u8, value });
        }
    }
}
```

```rust
/// `synth.unison = N` — set the unison voice count (clamped 1..=VOICES) on the
/// active allocator and the VoiceSum amplitude normalization to 1/√N.
pub(crate) fn synth_set_unison_impl<S: SlotApi>(vm: &S) {
    let n = (vm.get_f(1) as i64).clamp(1, deluge_audio_graph::poly::VOICES as i64) as usize;
    let out_node = self_synth(vm).out_node;
    self_synth(vm).alloc.set_unison(n);
    audio::set_param(out_node, 0, 1.0 / (n as f32).sqrt()); // VoiceSum gain
}

}
```
