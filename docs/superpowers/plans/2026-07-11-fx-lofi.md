```rust
//! Lo-fi degraders (Fx-2): `Bitcrush` (amplitude quantize) and `Decimate`
//! (sample-and-hold rate reduction). Mono, `no_std`. No anti-aliasing/dither —
//! the aliasing and quantization artifacts are the effect.

use crate::In; // same import path drive.rs/dynamics.rs use

/// Memoryless amplitude bit-depth reduction.
#[derive(Clone, Copy)]
pub struct Bitcrush {
    bits: f32,
}

impl Bitcrush {
    pub fn new(bits: f32) -> Bitcrush { Bitcrush { bits: bits.clamp(1.0, 24.0) } }
    pub fn set_bits(&mut self, b: f32) { self.bits = b.clamp(1.0, 24.0); }

    pub fn process(&mut self, input: In, _dt: f32, out: &mut [f32]) {
        let step = 1.0 / libm::powf(2.0, self.bits - 1.0); // 1 / 2^(bits-1)
        for i in 0..out.len() {
            let x = input.at(i);
            out[i] = libm::roundf(x / step) * step;
        }
    }
}

/// Sample-rate reduction by sample-and-hold. `rate_hz` = target rate.
#[derive(Clone, Copy)]
pub struct Decimate {
    rate_hz: f32,
    held: f32,
    phase: f32,
}

impl Decimate {
    pub fn new(rate_hz: f32) -> Decimate { Decimate { rate_hz: rate_hz.max(1.0), held: 0.0, phase: 1.0 } }
    pub fn set_rate(&mut self, hz: f32) { self.rate_hz = hz.max(1.0); }

    pub fn process(&mut self, input: In, dt: f32, out: &mut [f32]) {
        let inc = (self.rate_hz * dt).min(1.0); // rate/sr, capped (rate>=sr ⇒ passthrough)
        for i in 0..out.len() {
            self.phase += inc;
            if self.phase >= 1.0 {
                self.phase -= 1.0;
                self.held = input.at(i); // latch a fresh sample
            }
            out[i] = self.held;
        }
    }
}
```

Add `pub mod lofi;` to `crates/deluge-dsp-kernels/src/lib.rs` between `lfo` (line 16) and `math` (line 17).

## Self-Review Notes (for the executor)

- **Bitcrush is memoryless**, `step = 1/2^(bits-1)`, `out = round(x/step)·step` via `libm::roundf`. The `bitcrush_renders_on_grid` test (every output a multiple of the step) is the correctness oracle — don't loosen it.
- **Decimate holds:** phase accumulator `+= min(rate/sr, 1)`; latch on wrap; `phase` init 1.0 (first sample latches); `rate ≥ sr` → passthrough. `Decimate` USES `dt`; `Bitcrush` ignores it.
- **Both `#[derive(Clone, Copy)]`** — node `State` requires it.
- **Names are collision-resolved:** classes `Bitcrush`/`Decimate`; selectors `bitcrush_`/`decimate_`; setter `bits=` (free) + `decimateRate=` (`rate=` is TAKEN — do NOT reuse `node_set_rate`). Both tables + prelude selectors must match exactly.
- **Both classes `polyMode_`-guarded** (effects, not poly nodes).
- **Purely additive:** no existing kernel/node/effect/test changes. If an existing test needs editing, something is wrong.
- **Deferred (do NOT implement):** combined Crush node, anti-aliasing/dither, interpolation modes, stereo.
