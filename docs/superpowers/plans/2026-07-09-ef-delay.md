# Ef-1 Delay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a feedback delay effect (time / feedback / mix / damping) to the audio graph and Wren, built on a borrowed pooled ring buffer, and stand up the mutable-pool-region graph infrastructure the rest of the Ef suite reuses.

**Architecture:** A tiny `Copy` `DelayLine` primitive (write cursor only; ring buffer passed in per call) + a `Delay` effect kernel in a new `deluge-dsp-kernels/src/delay.rs`. The graph gains a `Kind::Delay` node whose ring buffer lives in the engine `Pool` (reusing the wavetable's `TableSrc::Pooled` binding); to write that region the node-render path's `pool_region` is widened from `Option<&[f32]>` to `Option<&mut [f32]>`. Wren exposes `Delay.new(input, time, feedback)` which allocates + binds the buffer via a new `Host::alloc_buffer` seam.

**Tech Stack:** Rust, `no_std`/no-heap kernels, `core::simd`-free scalar recurrence, Wren scripting via `wren-sys`, proptest for boundedness.

## Global Constraints

- **Kernels are `no_std`, no heap, pure `f32`, deterministic** (no RNG, no `Date`/time). The kernel owns **no** sample storage — the ring buffer is a borrowed `&mut [f32]` passed per call.
- **Host (non-`no_std`) tests run with `--target x86_64-unknown-linux-gnu`** (the repo default target is `armv7a-none-eabihf`; plain `cargo test` cross-compiles and fails to link).
- **Licensing: MIT/Apache-2.0.** Do NOT port spark's GPL-3.0 `deluge/fx/eq.rs` or `freeverb`. spark's delay is reference-only (its `FxEngine` is heap/`std`).
- **Port map for `Kind::Delay`:** port 0 = input (dry signal), port 1 = time (seconds), port 2 = feedback. `out_width` = 1.
- **Control-param map for `Kind::Delay`:** `set_param` index 0 = mix, index 1 = damping.
- **Wren setters:** `mix=` → `set_param(0)`; `damp=` → `set_param(1)`. Do **NOT** reuse `damping=` — it is already bound to `node_set_res_impl` (Resonator, port-2 `set_input`); a `Delay` node's port 2 is *feedback*, so routing `damping=` there would corrupt the feedback input. `damp=` is a fresh, unused selector.
- **`DELAY_MAX_SAMPLES = 48000`** (≈1.09 s @ 44.1 kHz, 1.0 s @ 48 kHz). The ring length is fixed at bind time.
- **Feedback is clamped to `[0.0, 0.98]`** inside the kernel for BIBO stability.
- **Graceful degradation, never panic:** a `Kind::Delay` node with no bound buffer (or a buffer shorter than 4 samples, or `alloc_buffer` returning `None`) renders **dry passthrough** (`out[i] = input.at(i)`), mirroring the wavetable's silence-on-missing-region.

```rust
//! Delay-line primitive and feedback delay effect. A `DelayLine` holds only a
//! write cursor; its ring buffer is a borrowed `&mut [f32]` passed per call
//! (1 s @ 48 kHz = 48000 f32 can't live in a `Copy` kernel struct). `no_std`,
//! no heap, deterministic. The `Delay` effect (Task 2) borrows the same buffer.

/// A delay line over a caller-owned ring buffer. Holds only the write cursor;
/// the ring buffer (`&mut [f32]`) is supplied on every `write`/`read`.
#[derive(Clone, Copy)]
pub struct DelayLine {
    w: usize,
}

impl DelayLine {
    pub fn new() -> DelayLine {
        DelayLine { w: 0 }
    }

    /// Write `x` at the cursor, then advance (wrapping on `buf.len()`).
    /// No-op on an empty buffer.
    pub fn write(&mut self, buf: &mut [f32], x: f32) {
        let len = buf.len();
        if len == 0 {
            return;
        }
        if self.w >= len {
            self.w = 0; // defensive: a shrunk buffer between calls
        }
        buf[self.w] = x;
        self.w += 1;
        if self.w >= len {
            self.w = 0;
        }
    }

    /// Read `delay` samples back from the write cursor, 4-point (3rd-order)
    /// Hermite interpolation. `delay` is clamped to `[1.0, len-2]`. Returns
    /// `0.0` for a buffer too short (< 4) to interpolate.
    pub fn read_hermite(&self, buf: &[f32], delay: f32) -> f32 {
        let len = buf.len();
        if len < 4 {
            return 0.0;
        }
        let d = delay.clamp(1.0, (len - 2) as f32);
        // Read position measured back from the write cursor.
        let rp = self.w as f32 - d;
        let i1 = floorf(rp);
        let frac = rp - i1;
        let base = i1 as isize;
        let at = |off: isize| -> f32 {
            // Euclidean wrap into [0, len).
            let idx = (base + off).rem_euclid(len as isize) as usize;
            buf[idx]
        };
        let xm1 = at(-1);
        let x0 = at(0);
        let x1 = at(1);
        let x2 = at(2);
        // Laurent de Soras 4-point 3rd-order Hermite.
        let c0 = x0;
        let c1 = 0.5 * (x1 - xm1);
        let c2 = xm1 - 2.5 * x0 + 2.0 * x1 - 0.5 * x2;
        let c3 = 0.5 * (x2 - xm1) + 1.5 * (x0 - x1);
        ((c3 * frac + c2) * frac + c1) * frac + c0
    }
}

impl Default for DelayLine {
    fn default() -> Self {
        Self::new()
    }
}

/// `floorf` without libm dependency creep here — small, finite positions.
#[inline]
fn floorf(x: f32) -> f32 {
    let i = x as i64 as f32;
    if x < i {
        i - 1.0
    } else {
        i
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn write_then_read_integer_delay_returns_written_sample() {
        let mut buf = [0.0f32; 64];
        let mut line = DelayLine::new();
        // Write a ramp 1,2,3,... then read integer delays back.
        for k in 1..=32 {
            line.write(&mut buf, k as f32);
        }
        // Last written was 32 (delay 1), previous 31 (delay 2), etc. Integer
        // delays hit taps exactly (frac == 0) so Hermite returns the sample.
        assert!((line.read_hermite(&buf, 1.0) - 32.0).abs() < 1e-3);
        assert!((line.read_hermite(&buf, 2.0) - 31.0).abs() < 1e-3);
        assert!((line.read_hermite(&buf, 5.0) - 28.0).abs() < 1e-3);
    }

    #[test]
    fn fractional_read_interpolates_between_neighbors() {
        let mut buf = [0.0f32; 64];
        let mut line = DelayLine::new();
        for k in 1..=32 {
            line.write(&mut buf, k as f32);
        }
        // Between delay 2 (31.0) and delay 1 (32.0): delay 1.5 ≈ 31.5 on a
        // linear ramp (Hermite is exact for a straight line).
        let mid = line.read_hermite(&buf, 1.5);
        assert!((mid - 31.5).abs() < 1e-3, "got {mid}");
    }

    #[test]
    fn wraps_around_without_panic_or_stale_read() {
        let mut buf = [0.0f32; 8];

        for k in 0..100 {
            line.write(&mut buf, k as f32);
        }
        // Most recent (delay 1) is 99.
        assert!((line.read_hermite(&buf, 1.0) - 99.0).abs() < 1e-3);
        // A clamped-large delay stays finite and in-buffer.
        assert!(line.read_hermite(&buf, 1000.0).is_finite());
    }

    fn short_or_empty_buffer_is_safe() {
        let mut empty: [f32; 0] = [];
        let mut line = DelayLine::new();
        line.write(&mut empty, 1.0); // no-op, no panic
        assert_eq!(line.read_hermite(&empty, 1.0), 0.0);
        let three = [1.0f32, 2.0, 3.0];
        assert_eq!(line.read_hermite(&three, 1.0), 0.0); // len < 4 → 0.0
    }
```

```rust
use crate::In;

/// Feedback delay effect over a borrowed ring buffer. Holds the delay line, a
/// one-pole damping state in the feedback path, and the mix/damping control
/// params. `process` borrows the ring buffer each block.
#[derive(Clone, Copy)]
pub struct Delay {
    line: DelayLine,
    damp_z: f32, // one-pole LP state in the feedback path
    mix: f32,    // dry/wet, [0,1]
    damping: f32, // feedback-path LP amount, [0,1] (0 = bright, 1 = frozen/dark)
}

impl Delay {
    pub fn new() -> Delay {
        Delay { line: DelayLine::new(), damp_z: 0.0, mix: 0.35, damping: 0.0 }
    }

    pub fn set_mix(&mut self, v: f32) {
        self.mix = v.clamp(0.0, 1.0);
    }
    pub fn set_damping(&mut self, v: f32) {
        self.damping = v.clamp(0.0, 1.0);
    }

    /// One block. `time` is in seconds (→ samples via `dt`), `feedback` is
    /// clamped to `[0, 0.98]` internally. `buf` is the pooled ring buffer;
    /// `out.len()` samples are produced.
    pub fn process(
        &mut self,
        input: In,
        time: In,
        feedback: In,
        dt: f32,
        buf: &mut [f32],
        out: &mut [f32],
    ) {
        let max_d = if buf.len() >= 2 { (buf.len() - 2) as f32 } else { 1.0 };
        // One-pole coefficient: damping 0 → g=1 (bright/no filtering),
        // damping→1 → g→0 (dark). g is applied as damp_z += g*(y - damp_z).
        let g = 1.0 - self.damping;
        for i in 0..out.len() {
            let x = input.at(i);
            let d = (time.at(i) / dt).clamp(1.0, max_d);
            let y = self.line.read_hermite(buf, d);
            self.damp_z += g * (y - self.damp_z);
            let fb = feedback.at(i).clamp(0.0, 0.98) * self.damp_z;
            self.line.write(buf, x + fb);
            out[i] = x * (1.0 - self.mix) + y * self.mix;
        }
    }
}

impl Default for Delay {
    fn default() -> Self {
        Self::new()
    }
}
```

```rust
/// Create a `Kind::Delay` node (ports 0/1/2 = input/time/feedback). A bound
/// `handle` emits `NewNode` + `BindTable{Pooled}`; an unbound one (alloc
/// failed) still creates the node but skips the bind, so it renders as dry
/// passthrough instead of panicking — the same contract as
/// [`new_wavetable_pooled`].
pub fn new_delay(id: u16, handle: Option<deluge_audio_graph::PoolHandle>, input: Input, time: Input, feedback: Input) {

    }

        node: NodeId(id),
        kind: Kind::Delay,
        args: [input, time, feedback],

            node: NodeId(id),
            src: deluge_audio_graph::node::TableSrc::Pooled(h),
        });
    }
}
```

## Scope notes (deliberate deferrals)

- **`DelayLine::allpass`** (Schroeder allpass, listed in the spec as an Ef-3 stub) is **omitted** here: it has no caller in Ef-1, and unused code is a review defect (YAGNI). It will be added in Ef-3 (Reverb), where the diffuser network uses it — with a real caller and tests.
- **Web/firmware `Host::alloc_buffer`** is not implemented in this plan (only the trait default + `EngineHost`). Pooled buffers already work only through `EngineHost` in the current tree (the web/firmware hosts don't override `upload_table` either), so pooled delay on those targets is the same pre-existing gap — a follow-up, tracked alongside the pooled-wavetable web support.
- **Soft output saturator** on the wet path is omitted: loop gain is clamped to 0.98 (BIBO-stable), the boundedness proptest confirms finiteness, and a saturator would distort the tail. If a hard bound is later required it is a one-line follow-up.
