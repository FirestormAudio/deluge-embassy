# Fi-3: Huovilainen Moog ladder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An authentic Moog ladder filter (12/24 dB slopes, resonance compensation, drive) as a thin `Moog<POLES>` kernel reusing the Fi-2 `DiodeLadder` core, plus graph + Wren.

**Architecture:** `Moog<const POLES: usize>` wraps `DiodeLadder<POLES>` + `pade_tanh` (already the Huovilainen tanh-cascade). Per sample it computes `fh`, pre-scales the input by `drive · (1 + MOOG_COMP·res)` (drive + resonance compensation), and calls the ladder's native `res·4` feedback path. Two node kinds give the 24/12 dB slopes; `drive` is a control param over the existing `Cmd::SetParam` path. No changes to `DiodeLadder`/`Tb303`.

**Tech Stack:** Rust (nightly), `no_std` kernels, `deluge-audio-graph`, `deluge-wren-core`, `deluge-dsp-test` (Fi-1 filter harness + spectrum).

**Spec:** `docs/superpowers/specs/2026-07-08-fi-moog-design.md`.

## Global Constraints

- `no_std`, `f32`, **scalar**. **No edits to `DiodeLadder`, `pade_tanh`, `Tb303`, `Svf`, `OnePole`** — Moog is purely additive; the default build and all existing tests stay green.
- Reuse the ladder verbatim: `DiodeLadder::<POLES>::new()` and `process(input: f32, fh: f32, res: f32, oversample: u32) -> f32`, and `pade_tanh`.
- Oversampling: a new `pub(crate) const MOOG_OVERSAMPLE: u32 = 2` (Huovilainen-canonical; Moog owns its own const, does not reuse `TB303_OVERSAMPLE`).
- Cutoff clamped `[20, 18_000]` Hz; res clamped `[0, 1]`; drive floored at 0, default 1.0.
- Ports: 0=input, 1=cutoff, 2=res. Drive is a **control param** (param index 0) via `Cmd::SetParam`, NOT a port.
- The two tuned constants (`MOOG_COMP`, `MOOG_K2`/`MOOG_K4`) are set **by measurement** using the QA gates — never by guessing, never by loosening a gate to fit a wrong value.
- Determinism: no RNG; proptests seed-fixed.

```rust
/// Moog ladder oversampling (Heun/RK2 integration sub-steps). Huovilainen-canonical 2×.
pub(crate) const MOOG_OVERSAMPLE: u32 = 2;

/// Resonance gain compensation: the input is pre-scaled by `1 + MOOG_COMP·res` so the
/// −3 dB cutoff stays put as resonance rises (Huovilainen input compensation). Tuned by
/// the `moog4_cutoff_stable_across_resonance` gate — do not guess.
pub(crate) const MOOG_COMP: f32 = 0.5;

/// Per-slope feedback scale so `res=1` self-oscillates cleanly. The ladder feedback is
/// `pade_tanh(y_last)·(res·MOOG_K)·4`; a 4-pole reaches self-osc at loop gain ~4
/// (`MOOG_K4 ≈ 1`), a 2-pole needs less. Tuned by the self-osc gates.
const MOOG_K4: f32 = 1.0;
const MOOG_K2: f32 = 1.0;

#[inline]
const fn moog_k(poles: usize) -> f32 {
    if poles <= 2 { MOOG_K2 } else { MOOG_K4 }
}

/// Authentic Moog transistor-ladder (Huovilainen) — a thin wrapper over the Fi-2
/// `DiodeLadder` (already the tanh one-pole cascade), adding resonance compensation and a
/// drive gain. `POLES` selects the slope (4 = 24 dB/oct, 2 = 12 dB/oct).
#[derive(Clone, Copy)]
pub struct Moog<const POLES: usize> {
    ladder: DiodeLadder<POLES>,
    drive: f32,
}

impl<const POLES: usize> Moog<POLES> {
    pub fn new() -> Self {
        Moog { ladder: DiodeLadder::new(), drive: 1.0 }
    }

    /// Pre-ladder input gain into the tanh (control param; 1.0 = clean).
    pub fn set_drive(&mut self, d: f32) {
        self.drive = d.max(0.0);
    }

    pub fn process(&mut self, input: In, cutoff: In, res: In, dt: f32, out: &mut [f32]) {
        let two_pi_dt_os = 2.0 * core::f32::consts::PI * dt / MOOG_OVERSAMPLE as f32;
        for (i, s) in out.iter_mut().enumerate() {
            let cutoff = cutoff.at(i).clamp(20.0, 18_000.0);
            let res = res.at(i).clamp(0.0, 1.0);
            let fh = two_pi_dt_os * cutoff;
            // drive + resonance gain compensation, then the ladder's native tanh feedback.
            let x = input.at(i) * self.drive * (1.0 + MOOG_COMP * res);
            *s = self.ladder.process(x, fh, res * moog_k(POLES), MOOG_OVERSAMPLE);
        }
    }
}

impl<const POLES: usize> Default for Moog<POLES> {
    fn default() -> Self {
        Moog::new()
    }
}
```

    fn slope_db_per_oct<const P: usize>(cutoff: f32) -> f32 {
        // Measure the stopband rolloff of an octave above cutoff, res low.
        let spec = spectrum::analyze(FS, |buf| {
            // white-ish impulse train → broadband excitation
            let mut x = std::vec![0.0f32; buf.len()];
            for k in (0..buf.len()).step_by(64) { x[k] = 1.0; }
            Moog::<P>::new().process(In::A(&x), In::K(cutoff), In::K(0.1), DT, buf);
        });
        // slope between 2×cutoff and 4×cutoff (one octave in the stopband)
        let a = spec.level_at(2.0 * cutoff).max(1e-9);
        let b = spec.level_at(4.0 * cutoff).max(1e-9);
        20.0 * (b / a).log10() // dB change per octave (negative)
    }

    #[test]
    fn moog_slopes_are_24_and_12_db_per_oct() {
        let s4 = slope_db_per_oct::<4>(800.0);
        let s2 = slope_db_per_oct::<2>(800.0);
        assert!(s4 < -18.0, "4-pole slope {s4} dB/oct (expect ≈ -24)");
        assert!(s2 < -8.0 && s2 > -18.0, "2-pole slope {s2} dB/oct (expect ≈ -12, distinct from 4-pole)");
        assert!(s4 < s2 - 6.0, "4-pole must roll off steeper than 2-pole ({s4} vs {s2})");
