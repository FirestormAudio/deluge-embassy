# Fi-4: MS-20 (Korg35) Sallen-Key filter — design & spec

The fourth sub-project of the **Fi (Filter) suite**: an authentic **Korg MS-20 / Korg35
Sallen-Key** filter — the screaming, diode-clipped 2-pole. A from-scratch zero-delay-feedback
Sallen-Key (two TPT one-pole integrators in a resonance loop with an **asymmetric diode-pair
clipper**), with switchable **LP/HP**, a **drive** knob, and a DC blocker. A genuinely
different topology from the ladders — no existing kernel is reusable as the core.

> **Status:** design proposal. Depends on merged Fi-1..Fi-3 (`svf_tan_prewarp` for the
> `g=tan(θ)` prewarp; `OnePoleHp` from `Tb303` for the DC blocker; the Fi-1 filter QA
> harness; the `Cmd::SetParam` control-param path). Nothing to port — neither spark nor
> skylib has a Sallen-Key/Korg35. Reuses the prewarp math + `OnePoleHp`; writes a new TPT
> one-pole primitive and a new asymmetric clipper.

**Fi roadmap:** Fi-1 SVF ✅ → Fi-2 TB-303 ✅ → Fi-3 Moog ✅ → **Fi-4 MS-20** (this spec) →
Fi-5 modal resonator.

---

## 1. Goals & non-goals

**Goals**
- **ZDF Sallen-Key core.** Two TPT one-pole lowpasses (`g = tan(π·fc·dt)`, via the reused
  `svf_tan_prewarp`) in a Sallen-Key feedback loop. The nonlinear clip sits on the
  **state-dependent feedback signal** `S` (a function of the two integrator states, known
  *before* the sample's ZDF solve), so the delay-free loop is solved **without iteration** —
  cheap and stable.
- **Asymmetric diode-pair clipper (the MS-20 scream).** The resonance feedback is clipped by
  a hard, **asymmetric** saturator (a driven diode pair clips one polarity harder), producing
  the aggressive, even-harmonic-rich MS-20 distortion. `k` (resonance) drives toward the
  self-oscillation threshold; the clipper — not `k` — sets the sustained self-osc amplitude.
- **DC blocker.** The asymmetric clip introduces a DC offset; a one-pole high-pass (the
  existing `OnePoleHp` at a low corner, ~5–20 Hz) on the output removes it.
- **LP and HP variants.** The Korg35 LP and HP Sallen-Key arrangements → two node kinds; both
  2-pole (~12 dB/oct), resonant, self-oscillating.
- **Drive.** A pre-clip input gain (control param) for the overdriven scream.
- **QA-proven:** self-oscillation (both modes, bounded/clip-limited), resonant-peak tracking,
  correct LP/HP band + slope, drive raises THD, **measurable even harmonics** (asymmetry),
  **output DC ≈ 0** (DC blocker), boundedness, cutoff accuracy.

**Non-goals (deferred / out of scope)**
- **Audio-rate drive** — control param via `Cmd::SetParam` (like Moog's), not a 4th port.
- **The full MS-20 HP→LP series chain / the two-filter routing** — ship the LP and HP as
  independent selectable filters; chaining them is a patching concern.
- **Newton-iterated ZDF** — the state-feedback-clip formulation is iteration-free; a full
  per-sample Newton solve is a later refinement only if the fixed form proves insufficient.
- **Thermal/component drift, exact Korg35 SPICE fidelity** — a VA model, gated behaviorally.
- **Cross-voice SIMD** (voice/`Sy` layer). No edits to `Svf`/`DiodeLadder`/`Tb303`/`Moog`.

## 2. Kernel DSP (`deluge-dsp-kernels/src/filter.rs`, new `Ms20`)

**TPT one-pole primitive (new — none exists).**
```rust
// One zero-delay-feedback one-pole lowpass step. `g = tan(π·fc·dt)`; state `s`.
// Returns (y, new_s). G = g/(1+g); v = (x − s)·G; y = v + s; new_s = y + v.
#[inline]
fn tpt_lp1(x: f32, s: f32, g: f32) -> (f32, f32) { … }
```

**Asymmetric diode clipper (new).** A pure-arithmetic saturator that clips positive and
negative excursions differently (harder one side), modeling a diode pair — adds even
harmonics and a DC offset. Exact form pinned in the plan (e.g. a biased/two-sided
`pade_tanh`-style rational, or `tanh(x+b)−tanh(b)` with a hardness factor); must be
monotonic, bounded, pure `f32`.

```rust
pub(crate) fn ms20_clip(x: f32) -> f32 { … }   // asymmetric, hard-kneed, bounded
```

**`Ms20` struct & response.**
```rust
#[derive(Clone, Copy)]
pub enum Ms20Resp { Lp, Hp }

pub struct Ms20 {
    s1: f32, s2: f32,     // the two TPT one-pole integrator states
    dc: OnePoleHp,        // output DC blocker (low corner), removes the clip's DC offset
    drive: f32,           // control param, default 1.0
}

impl Ms20 {
    pub fn new() -> Ms20;                 // dc corner set on first process (dt-keyed)
    pub fn set_drive(&mut self, d: f32);
    pub fn process(&mut self, input: In, cutoff: In, res: In, resp: Ms20Resp, dt, out: &mut [f32]);
}
```

**Per-sample (Korg35 LP; HP is the analogous Sallen-Key HP arrangement):**
1. `g = svf_tan_prewarp((π·fc·dt).min(0.49π))`, `G = g/(1+g)`; `res` → resonance gain `k`
   (clamped; `k` at/above the loop threshold self-oscillates).
2. Compute the **state-dependent feedback** `S` (the Sallen-Key's zero-input response — a
   function of `s1`, `s2`, `G` only, independent of the current input).
3. **Clip the feedback:** `fb = k · ms20_clip(drive · S)`.
4. **Linear ZDF solve** for the two one-poles with `x − fb` as the effective input (the loop
   is now linear because the nonlinearity was applied to the known `S`). Produce the LP (or
   HP) response from the integrator outputs; advance `s1`, `s2`.
5. `out[i] = dc.process(y)` — DC-block the (asymmetrically-clipped) output.

**Oversampling:** the clip acts on the bounded feedback `S`, so aliasing is milder than the
ladders. Ship a measured factor — start 2×, **measure-down to 1× if aliasing holds** (as Fi-2
did). A `const MS20_OVERSAMPLE` config point.

`no_std`; pure `f32` hot path (`libm::tan` f64 only for the DC-blocker corner, once per `dt`);
deterministic; state is fixed-size. No SIMD.

  in both binding tables + `class Ms20` in `prelude.wren`.

## 4. QA acceptance & testing

Reuse the Fi-1 harness (`filter_meas::{magnitude_db, minus_3db_hz, self_osc_hz_and_rms}`) and
`spectrum::{analyze, thd, level_at, slope_db_per_octave}`.

**`deluge-dsp-kernels` tests:**
- **Self-oscillation, both modes.** At high `res` with a brief excitation, LP and HP each
  sustain a bounded tone near `cutoff` — validates the loop threshold and that the clipper
  bounds the amplitude (a wrong/absent clip diverges).
- **Resonant peak tracks cutoff** and grows with `res`.
- **Correct band + slope.** LP passes lows / attenuates highs (≈ −12 dB/oct via
  `slope_db_per_octave`), HP the reverse. Cutoff (−3 dB point at low res) near set `cutoff`.
- **Drive raises THD.** `thd` at `drive=4` ≫ at `drive=1`.
- **Asymmetry → even harmonics (the character gate).** Drive a sine; assert the **2nd
  harmonic** is present at a meaningful level (the symmetric ladders would suppress it) —
  proves the asymmetric clip.
- **DC blocker works.** Despite the asymmetric clip, the output's DC / mean is ≈ 0 (below a
  small threshold) over a sustained render.
- **Boundedness (P0 gate).** Proptest: `cutoff ∈ [20, 18k]`, `res ∈ [0,1]`, `drive ∈ [1,8]`,
  bounded input → finite, within a measured bound.
- **Oversampling characterization** (informational, like Fi-2): pick `MS20_OVERSAMPLE` from
  an OS=1/2/4-vs-reference measurement; a `DiodeLadder`-style guard is not needed, but record
  the chosen factor's justification.

**Graph/Wren:** `Kind::Ms20Lp`/`Ms20Hp` render bounded/non-silent; `Ms20.lp`/`Ms20.hp` emit the
right `Cmd`; `drive=` changes output; `cutoff=`/`res=` update the node.

**Determinism:** no RNG; reproducible; proptests seed-fixed.
